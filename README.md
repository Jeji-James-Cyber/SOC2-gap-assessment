# SOC 2 Control Inventory and Gap Assessment (Fictional SaaS Company)

> **Disclaimer:** This is a fictional readiness assessment created for portfolio and learning purposes. It is not a SOC 2 audit or report. Only a licensed CPA firm can issue a SOC 2 report.

## Overview
A control inventory and gap assessment mapping a fictional SaaS company's security practices to the AICPA Trust Services Criteria, with a prioritised remediation roadmap.

## Repository structure
- `/inventory` - control inventory spreadsheet (.xlsx and .csv)
- `/report` - PDF report
- `/diagrams` - system and data-flow diagrams
- `/docs` - company profile, scope, methodology
